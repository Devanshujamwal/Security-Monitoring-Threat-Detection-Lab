# Security Monitoring & Threat Detection Lab

**Wazuh · SIEM · Windows/Linux · Wireshark · Palo Alto concepts**

A hands-on cybersecurity lab focused on endpoint visibility, event review, network context, and structured investigation.

## What I worked on
- Windows and Linux event visibility
- Wazuh / SIEM fundamentals
- Network telemetry with Wireshark
- Firewall and policy concepts
- Alert triage and investigation reasoning

## Investigation approach
Validate the source, timestamp, endpoint context, network activity, and related events before treating an alert as a confirmed incident.
